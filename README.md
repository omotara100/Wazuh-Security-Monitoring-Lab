# Wazuh Security Monitoring Lab

> 🚧 **Project Status: In Progress**

## Overview

This repository documents my hands-on implementation of an on-premises security monitoring environment using Wazuh.

The lab is designed around a centralized Wazuh deployment with Windows and Linux endpoints. As the environment is built, this repository will document the technical implementation, configuration decisions, validation evidence, telemetry analysis, detection logic, and security investigation findings.

The focus is not only on configuring the platform, but also on understanding what the collected security evidence shows and using that evidence to make defensible security decisions.

## Lab Environment

The environment is being built using three virtual machines:

| System           | Purpose                                      |
| ---------------- | -------------------------------------------- |
| Wazuh Server     | Centralized security monitoring and analysis |
| Windows Endpoint | Windows security and endpoint telemetry      |
| Ubuntu Endpoint  | Linux security and system telemetry          |

## Documentation Approach

Each completed stage will be documented based on the work actually performed and validated.

Documentation will focus on:

* What I built
* What I configured
* How I validated the configuration
* What telemetry was collected
* What the evidence showed
* What problems I encountered and how I resolved them
* What security conclusions the evidence supported
* What I would improve or investigate further
